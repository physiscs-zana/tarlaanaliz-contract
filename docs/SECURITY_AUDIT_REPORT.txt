2. CRITICAL BULGULAR (4)
================================================================================

[C-01] Platform — Hardcoded Bypass Credentials
  Dosya  : src/presentation/api/v1/endpoints/auth.py:115
  Açıklama: phone=="+905555555555" ve pin=="123456" koşulu ile tüm
            authentication bypass edilebilir. Production ortamında
            herkes bu kimlik bilgileriyle giriş yapabilir.
  Etki   : Tam hesap erişimi, veri sızıntısı, KVKK ihlali
  Düzeltme: Hardcoded koşul tamamen kaldırılmalı. Dev/test ortamı için
            ayrı test fixture kullanılmalı, production kodda bypass OLMAMALI.

[C-02] Platform — JWT Secret Default Value
  Dosya  : src/presentation/api/settings.py:89
  Açıklama: JWT_SECRET_KEY default değeri "CHANGE-ME-IN-PRODUCTION".
            .env dosyası yoksa veya değişken tanımlanmamışsa bu değer
            kullanılır ve tüm JWT token'ları tahmin edilebilir.
  Etki   : Token forgery, tam API erişimi
  Düzeltme: Default değer kaldırılmalı, env yoksa uygulama başlatılmamalı
            (fail-closed). Startup'ta zorunlu kontrol eklenmeli.

[C-03] Edge — Sıfır Authentication
  Dosya  : src/presentation/api/endpoints/*.py (tüm endpoint'ler)
  Açıklama: Edge API'de hiçbir authentication middleware yok. Tüm
            endpoint'ler anonim erişime açık. Ağa erişen herkes
            dataset upload, sync, pipeline tetikleme yapabilir.
  Etki   : Yetkisiz veri manipülasyonu, kötü amaçlı dosya yükleme
  Düzeltme: API key veya token tabanlı middleware eklenmeli. Kiosk
            ortamında en azından shared secret veya mTLS kullanılmalı.

[C-04] Edge — HC-05 Kalibrasyon Hard Gate Devre Dışı
  Dosya  : src/presentation/api/endpoints/sync.py:123-129
  Açıklama: Kalibrasyon kanıtı (calibration_result.json, manifest.sha256)
            eksik olduğunda kod "pass" ile devam ediyor. Yorum:
            "Non-fatal for MVP; real validation done server-side".
            Bu, kalibre edilmemiş verinin upload edilmesine izin verir.
  Etki   : Kalibre edilmemiş veri ile yanlış analiz sonuçları
  Düzeltme: CalibratedValidator (calibrated_validator.py) sync endpoint'ine
            bağlanmalı. Kalibrasyon eksikse upload reddedilmeli (HTTP 422).

[H-01] Platform — python-jose CVE'leri
  Dosya  : pyproject.toml (python-jose[cryptography]>=3.3.0)

  Düzeltme: PyJWT veya joserfc'ye geçiş

[H-02] Platform — JWT iss/aud/exp Doğrulaması Yok
